    Multi-Modal Fusion Weights & Architecture

    Interactive Tuner

    The ScamShield fusion engine combines independent modality scores into a unified 0-100 verdict. Default weights: 55% Text (NLP ML) and 45% URL (Lookalike heuristics). A 3rd placeholder weight (Transaction Risk) is built-in for zero-rewrite extensibility.

    Text Risk Scorer Weight (wtext): 0.55
    URL Risk Scorer Weight (wurl): 0.45
    Transaction Weight Placeholder (wtxn): 0.00

    Live Simulation with Sample (Text: 86, URL: 94):

    (0.55 * 86) + (0.45 * 94) = 89.6 → Dangerous
